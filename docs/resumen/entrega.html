1. Direcciones del proyecto

  • Sitio público: norte-aventura-salta.vercel.app
  • Backoffice (administración): norte-aventura-salta.vercel.app/admin
  • API (servidor): norte-aventura-sa.vercel.app
  • Repositorio: github.com/thiagourcvazquez-coder/NorteAventuraSA

Cada cambio que se sube a GitHub (rama main) dispara un deploy automático en Vercel en unos minutos.

2. Acceso al backoffice

URL: norte-aventura-salta.vercel.app/admin

Usuario: norteaventura@agencia.com

Contraseña: NorteAventura123_

Estas credenciales deben estar cargadas como variables de entorno en Vercel, en el proyecto norte-aventura-sa (el server) → Settings → Environment Variables:

ADMIN_USERNAME = norteaventura@agencia.com ADMIN_PASSWORD = NorteAventura123_ ADMIN_SECRET = (cualquier texto largo aleatorio)

Después de cargarlas: Deployments → último → Redeploy para que tomen efecto.

3. Qué incluye el backoffice

Dashboard

  • Reservas del mes, pendientes de confirmar, ingresos y egresos del mes, comentarios por moderar, excursiones activas.

Reservas

  • Listado completo con filtro por estado; se puede cambiar cada reserva a pendiente / confirmada / cancelada.
  • Se ve quién pagó por Mercado Pago y quién todavía no.

Finanzas (caja)

  • Carga de movimientos: Ingreso o Gasto, con descripción, monto, categoría, fecha, método de pago y notas.
  • Balance del mes (ingresos menos egresos) con navegación entre meses.
  • Gráfico por categoría con selector ingresos/egresos y tabla de movimientos del mes con edición y borrado.

Comentarios / testimonios

  • Los visitantes pueden dejar su opinión desde la página principal (sección de testimonios).
  • Entran como "pendientes": desde el panel se aprueban, rechazan, destacan o borran.
  • También se pueden cargar testimonios a mano con nombre, origen, estrellas y excursión.

Excursiones

  • Crear, editar y desactivar excursiones: precio, duración, dificultad, tipo (clásica / trekking / privada), imágenes, mapa, orden de aparición.

4. Base de datos (Supabase)

Se agregaron dos tablas nuevas. El SQL está en supabase/migration-backoffice.sql y hay que ejecutarlo una sola vez en Supabase → SQL Editor:

  • finances — movimientos de ingresos y egresos; solo accesible desde el panel.
  • comments — testimonios; el público solo lee los aprobados y solo puede enviar nuevos (quedan pendientes).

6. Mercado Pago — qué falta para activarlo

El código ya está completo: cuando alguien reserva, el sitio genera un link de pago de Mercado Pago (Checkout Pro) y, cuando MP confirma el cobro, la reserva se marca como pagada sola. Lo único que falta son las credenciales de la cuenta de Mercado Pago de la agencia.

Pasos para activarlo

  • Entrar a mercadopago.com.ar/developers/panel con la cuenta de Mercado Pago de la agencia.
  • En "Tus integraciones" → crear una aplicación (nombre: Norte Aventura) o abrir la que ya exista.
  • Ir a Credenciales y copiar el Access Token de PRODUCCIÓN (empieza con APP_USR-).
    El token de prueba (TEST-) es opcional: sirve para probar el flujo sin cobrar plata real.
  • En Vercel → proyecto norte-aventura-sa → Settings → Environment Variables, cargar:
MP_ACCESS_TOKEN = APP_USR-... (el token de producción) PUBLIC_URL = https://norte-aventura-sa.vercel.app CLIENT_URL = https://norte-aventura-salta.vercel.app
  • Hacer Redeploy del proyecto server.

Recomendado: webhook

  • En el panel de MP → Webhooks → suscribir el evento "Pagos" a https://norte-aventura-sa.vercel.app/api/payments/webhook.
  • Copiar la firma secreta que genera MP y cargarla como MP_WEBHOOK_SECRET en Vercel.
Importante: sin MP_ACCESS_TOKEN el botón de pago ni siquiera aparece — el formulario sigue funcionando solo por WhatsApp. Sin webhook el cobro se realiza igual, pero la reserva no se marca como pagada automáticamente.
